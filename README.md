# Family Remote Support - Native Android Application
> "Helping family, from anywhere."

Production-Ready Android Application built with **Kotlin**, **Jetpack Compose**, and **Material 3**.

## Features
- Single-Activity Architecture (`MainActivity.kt`)
- Material 3 Dynamic Color Schemes & Typography (`ui/theme/`)
- Jetpack Compose Navigation Graph (`ui/navigation/NavGraph.kt`)
- ViewModel with StateFlow state management (`viewmodel/SupportSessionViewModel.kt`)
- Multi-language support (English & Sinhala)
- End-to-End Encrypted Peer-to-Peer Remote Support Architecture

## How to Open in Android Studio
1. Unzip this directory.
2. Open Android Studio (Ladybug / Hedgehog or newer).
3. Select "Open Project" and choose this folder.
4. Gradle will automatically sync dependencies.
5. Click "Run" on any Android Device or Emulator (API 26+).
